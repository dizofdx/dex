Продвинутое окружение рабочего стола для **Samsung Galaxy A55** на базе виртуального второго дисплея `scrcpy`, нативного многооконного режима Android Freeform и аппаратного ускорения **HEVC (H.265)**.

---

## 📖 Предыстория и аппаратные особенности

В смартфонах серии Galaxy A (включая флагман линейки A55 5G) компания Samsung программно вырезала флагманский лончер Samsung DeX (`com.sec.android.app.desktoplauncher`), а порт Type-C аппаратно работает по стандарту USB 2.0 без поддержки **DisplayPort Alternate Mode**.

### Как решена задача в DeX Pro:
1. **Проводной режим (USB)**: Видеопоток 1080p 60fps транслируется с минимальной задержкой (**~15 мс**) через ADB-туннель.
2. **Беспроводной режим (Wi-Fi TCP/IP)**: Видео передается по локальной сети через порт 5555. Скрипт сам определяет IP-адрес смартфона.
3. **Роль Bluetooth**: Передача видео по Bluetooth невозможна из-за физического лимита пропускной способности (1.5–2 Мбит/с), однако Bluetooth используется для:
   - Подключения мыши и клавиатуры напрямую к смартфону;
   - Подключения беспроводных наушников (Galaxy Buds) без задержки звука (`--no-audio`).

## ✨ Ключевые возможности

| Функция | Преимущество |
| :--- | :--- |
| **Аппаратный энкодер Exynos 1480** | Используется `c2.exynos.hevc.encoder` (H.265) на битрейте 16 Mbps 60 FPS — кристально четкий текст. |
| **Автозапуск Smart Launcher** | Автоматически стартует полноэкранный рабочий стол Smart Launcher (`ginlemon.flowerfree`) на виртуальном мониторе. |
| **Плотность 160 DPI (MDPI)** | Идеальное масштабирование 1:1 (`1920x1080/160`) без замыливания интерфейса. |
| **Защита батареи и экрана** | Экран смартфона автоматически выключается (`--turn-screen-off`), снижая нагрев и энергопотребление. |
| **Защита от засыпания** | Телефон не уходит в спящий режим во время работы (`--stay-awake`). |
| **Быстрый запуск с ярлыка** | Ярлык `Samsung DeX (USB Fast)` на Рабочем столе запускает сессию в 1 клик. |

## 🛠 Требования

1. Смартфон **Samsung Galaxy A55 5G** (или любой Galaxy серии A / M / S).
2. Включенная **Отладка по USB** (USB Debugging) в меню разработчика.
3. Установленный [scrcpy v3.3+](https://github.com/Genymobile/scrcpy) для Windows.
4. Установленный рабочий стол на смартфоне: **Smart Launcher 6** или **Taskbar** (Farmerbb).

## 🚀 Быстрый старт

### Вариант 1: Запуск по кабелю (USB)
1. Подключите телефон кабелем USB к компьютеру.
2. Запустите ярлык **`Samsung DeX (USB Fast)`** на Рабочем столе (или выберите пункт `1` в `Samsung DeX Pro.bat`).
3. Экран телефона погаснет, а на компьютере откроется рабочий стол DeX.

### Вариант 2: Беспроводной режим (Wi-Fi)
1. Убедитесь, что телефон и ПК подключены к одной сети Wi-Fi.
2. Запустите ярлык **`Samsung DeX`** и выберите пункт `4` (первичная активация порта 5555 через USB).
3. Отключите USB-кабель и выберите пункт `2` (Запуск по Wi-Fi).

## ⌨️ Горячие клавиши управления

- `Alt + F` — полноэкранный режим / оконный режим.
- `Alt + H` — кнопка **Домой** (Home).
- `Alt + B` — кнопка **Назад** (Back).
- `Alt + S` — список недавних приложений (многозадачность).
- `Ctrl + Пробел` или `Shift + Пробел` — переключение языка физической клавиатуры (RU / EN).
